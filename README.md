# SciTeX Live Paper demo

A small scientific viewer example built as a repository. Eight synthetic
sensor readings live in an input ZIP. The reported count, mean absolute error,
and FigRecipe plot trace through a recorded Clew run to that exact archive.

## Open the paper

```bash
uv run scitex-live-paper serve .
```

Open http://127.0.0.1:8765. Hover over a result or the figure edge to see its
graph. Open the archive node to browse the recorded files. Select
`measurements.csv` for the actual data. Hover over `analyse.py` to see the
matching script. The review summary links to the machine-readable packet at
`/review.json`.

`manuscript.pdf`, the plotted figure, the claim snapshot, and the evidence
report are generated by the scripts below. File previews are generated by
Live Paper from the original bytes when requested.

## Reproduce

Provide a writable PostgreSQL store for Clew and export its connection as
`SCITEX_STORE_DSN`. The bundled snapshot can be viewed without PostgreSQL.

```bash
uv run python analyse.py
uv run python build_paper.py
```

SciTeX Stats calculates the mean absolute error. FigRecipe renders the plot.
Clew records the inputs, outputs, and producing script. Live Paper exposes
the same graph and file previews to the browser and external clients.

The records are synthetic. Verification covers the recorded calculation
trace for the demo.
